# Proyecto-IA-udp---Admisi-n
Sistema inteligente de predicción de ingreso a la educación superior en Chile mediante Aprendizaje Supervisado (DEMRE + MINEDUC), implementado con comparación de modelos (Naive Bayes, Árboles de Decisión, Random Forest) y un asistente conversacional interactivo (Gradiante/Chatbot) orientado a la orientación vocacional.
